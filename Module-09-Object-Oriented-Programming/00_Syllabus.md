# Module 09 — Object-Oriented Programming

## Objective

Develop a strong understanding of Object-Oriented Programming in Python, from fundamental concepts through inheritance, polymorphism, abstraction, composition, dependency injection, OOP design, exception handling, and automation-oriented object design.

# Learning Principle

The module progresses from:

```text
Objects
   ↓
Classes
   ↓
Encapsulation
   ↓
Methods
   ↓
Special Methods
   ↓
Identity
   ↓
Inheritance
   ↓
Polymorphism
   ↓
Abstraction
   ↓
Composition
   ↓
Dependency Injection
   ↓
OOP Design
   ↓
Exception Handling
   ↓
Automation-Oriented Design
   ↓
Practical OOP
```

The concepts are learned progressively so that later OOP design topics build on the earlier foundations.

---

# End Goal

By the end of this module, the learner should understand how Python objects are created, structured, related, extended, validated, and designed for reuse and testability, including how OOP concepts can support automation-oriented software design.
